# Privacy Sentinel — Minimal Implementation

This workspace contains a minimal, simple implementation of the Privacy Sentinel project described in your document.

Quick start

1. Create and activate the venv (the workspace may already have one configured).
2. Install dependencies: `pip install -r requirements.txt`.
3. Run the Streamlit app: `streamlit run app.py` and open the provided URL.

What is included

- `privacy_sentinel/` — package with `db_setup`, `comparator`, `scoring`, `data_manager`.
- `app.py` — minimal Streamlit UI to paste two labels and compare.
- `requirements.txt` — minimal requirements.
